# Optional editable delivery

Use only when editable artwork is requested. Preserve the approved image's meaning
and appearance rather than restarting the design.

Use native text and chemical character formatting; native circles, panels, numbered
badges, leaders and connectors for measurable structure. An arrow owns its head in
one object. Complex biological parts may remain independently movable bounded
pictures when consistent with the user's request and rights. State that limit.

Do not place an entire figure/panel bitmap behind native labels and call the image
object-level editable. Remove old labels/lines/borders before adding native ones.
Preserve pale biological edges and opaque white interiors: aggressive alpha/color
thresholds can erase basement membranes or crop cell processes.

When available, use a dedicated reconstruction workflow such as nature-image2ppt.
Honor its current manifest/build/render schemas and path boundaries. Do not build
a competing controller, modify a validator to pass or label copied pixels as a new
image-model output. A source-faithful component sheet records separation honestly.

Measure actual ellipses instead of assuming circles. Preserve route endpoints,
curves, inhibition caps and bends. Use a complete native freeform arrow if a preset
would straighten the curve or make an incorrect S. Record such paths separately
from connector types supported by the automatic inspector.

Calibrate source ink at actual slide scale. General fitting can wrongly shrink
condensed fonts; disable it only for measured and inspected boxes. Use native
baseline runs when a font lacks chemical subscript glyphs. Preserve hierarchy and
column gaps as well as word presence.

Build from the authoritative native source, then export through a real presentation
renderer. Compare every page with its source: white bands, gradient seams, old
arrow fragments, duplicate frames, cropped processes and text collisions are common.
Serialize actual desktop-render calls if workers share one renderer; writing and
reviewing should not hold that slot. Render the combined deck again after assembly.

Bind review to current source/render hashes. Report native objects separately from
pictures; counts are not an editability percentage. Deliver native source, bounded
assets/provenance, actual renders, review and file manifest. Use approved native
source exports downstream when requested, respecting any user approval checkpoint.
